# Supabase SQL migrations

These files are the source-controlled history of database changes for the
project. The three `2026-07-28` files were restored from the original project
history after verification that their effects already exist in the live
database.

Before applying a historical migration to an existing project, inspect the
live schema first. Do not rerun a script merely because it was added to this
folder later. Apply new migrations in date order through the Supabase SQL
Editor, then retain the successful script here.
